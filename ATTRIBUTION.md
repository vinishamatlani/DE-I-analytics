## Adaptation

This portfolio project substantially reframes the original employee
engagement survey workflow into a synthetic:

**Global Inclusion & Belonging Analytics**

use case.

The adaptation includes:

- Inclusion Index construction
- Five inclusion dimensions
- Inclusion outcome measures
- Region, gender-group and age-band segmentation
- Inclusion gap analysis
- Confidentiality suppression
- Inclusion association analysis
- Synthetic DE&I event data
- DE&I event effectiveness analysis
- Executive inclusion dashboard
- Intervention measurement framework

## Data

All employee survey data and DE&I event data used in this portfolio
project are synthetic.

No real employee records or confidential organisational data are
included.
