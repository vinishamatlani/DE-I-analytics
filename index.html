Methodology & Ethics

This project uses synthetic data for portfolio demonstration. No real employee information is used.

Segment results with fewer than five respondents are suppressed to demonstrate a basic confidentiality protection.

Association analysis describes statistical relationships only and should not be interpreted as causal evidence. The survey instrument is illustrative and has not undergone external psychometric validation. Production use would require appropriate reliability, construct-validity, measurement-invariance and fairness evaluation.
